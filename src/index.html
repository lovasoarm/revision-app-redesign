TABLEAU DE BORD

Votre mémoire, en mouvement.

Un aperçu net de ce qui demande votre attention, puis l'espace de travail pour construire votre arbre d'apprentissage.

Catégories

+ Nouvelle catégorie

Une catégorie regroupe un univers d'apprentissage complet et séparé des autres (ex. Informatique, Psychologie, Langues). Tout module se range obligatoirement sous une catégorie, directement ou via un sous-module.

+ Nouveau module

Choisissez une catégorie pour un module de haut niveau, ou un module existant pour créer un sous-module : sans limite de profondeur. Astuce : le bouton « + module » / « + sous-module » sur une carte règle ce champ automatiquement et déplie ce formulaire. Description et « à retenir » restent modifiables à tout moment depuis la carte du module.

Données

Stockage local : …. Aucune donnée ne quitte votre machine.

Export : dans l'app Tauri, une fenêtre native « Enregistrer sous » s'ouvre pour choisir l'emplacement exact. En navigateur, le fichier part dans votre dossier Téléchargements habituel : un message le confirme après l'export.

Import : le fichier est vérifié avant tout remplacement (structure, ids uniques, parents valides). En cas de fichier invalide, l'import est bloqué et le détail des erreurs s'affiche ; sinon une confirmation indique le nombre de modules et d'évènements avant d'écraser les données actuelles.
